# DevClubPortal

## 💻 Tech Stack

### Frontend Architecture

- **HTML5:** Semantic architecture for layout formatting
- **CSS3:** Custom native properties mapping an aesthetic glassmorphism design (No External Libraries)
- **Vanilla JavaScript:** Native DOM manipulation & asynchronous API bindings (`fetch`)

### Backend Services

- **Node.js**: Asynchronous JavaScript runtime
- **Express.js**: RESTful framework constructing robust routers and statically serving `public` files.
- **Multer**: Native middleware for actively handling `multipart/form-data` logic to process image uploads seamlessly onto the server disk.

### Authentication & Data Security

- **Cookie-Parser**: Specialized middleware safely parsing signed HTTP-Only server-side cookies out of Request headers.
- **Bcrypt**: Cryptographic hashing utility scrambling members' passwords against brute-force intrusion techniques pre-storage.

### Database

- **SQLite3**: A resilient Serverless SQL native database
- **sqlite**: Promise-based wrapper streamlining asynchronous DB reads and writes without deep nesting callbacks.
